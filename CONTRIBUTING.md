# Contributing

Bug reports, ideas and pull requests are welcome.

- Open an issue first for big changes, so we can agree on the idea.
- Keep the UI clean and minimal (no emoji) and use Material 3 components and theme attributes, not hard-coded colours.
- Test on a real device when you touch tabs, profiles, animations or downloads.
- By contributing you agree that your work is released under the GNU GPL v3.0 or later (see `LICENSE`).
